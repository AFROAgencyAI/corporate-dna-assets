# Little Life Moment · Activity Posters (A4 portrait WebP)

Marketing posters for LLM programmes, **content-cropped to A4 portrait** from `Posters.pdf` (Canva landscape pages that hold 1–2 A4 posters each).

**Use on landing pages:** each folder’s `cover.webp` is the main event poster. `panel-02.webp` / `panel-03.webp` are stations / alternate layouts when present.

## Specs

- Orientation: **portrait only**
- Aspect ratio: **A4** (210×297 → w/h ≈ 0.707)
- Pixels: **1200 × 1697** WebP
- Count: 23 programmes · **47** posters
- Source PDF: 43 landscape pages (most 1-up A4 centered; pages 4, 9, 11, 35 are 2-up)
