# Little Life Moment · Activity Posters (tight WebP cuts)

Event posters cut out of `Posters.pdf` landscape Canva pages. **No white canvas strips.** Native poster aspect (usually ~0.66–0.80 portrait).

**Landing pages:** use each folder’s `cover.webp` only unless you need station/detail panels.

## Specs

- Orientation: portrait (content crop, not forced A4 letterbox)
- Typical size: ~1200–1400 × 1800 WebP
- Count: 23 programmes · **46** posters (P20/P21 split 2+2)
- Source: 43 PDF pages; pages 4, 9, 11, 35 are 2-up (split L/R)
